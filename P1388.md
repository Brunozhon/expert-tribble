# P1388

This is an **interval DP** problem.

To efficiently compute ranges for this problem, we can use a prefix sum array for the sums of the numbers in parentheses to make sum operations faster.

To solve the problem, we DP over every possible interval of the whole sequence. For each interval, we choose a element to split the array. The left interval will use the DP array, the right interval will just use the sum of the elements, and the two will be multiplied together. The maximum of these calculations will be the DP for the current interval. The pseudocode for this is:

```
for every interval:
    for every split from left to right - 1:
        find the DP of the left half
        find the sum of the right half
        multiply the two results together
    find the maximum of the results and save it as the DP
```

With this approach, the time complexity is **`O(n²)`**.
