# P10135: Potion Farming (Sliver)

This is a **tree DP problem** with two parts:

1. Finding the minimum amount of traversals.
2. Finding the maximum amount of potions that can be collected in the amount of traversals.

We can take advantage of a key insight to solve the first part: the minimum number of traversals for any node is the number of leaf nodes connected to it. Using DFS, we can store the minimum number of traversals in an array. The psuedocode for the DFS function is:

```
if this node is a leaf node:
    add one to global number of traversals
    add one to the number of traversals for this node
for each child of this node:
    DFS again
    add the number of traversals for the child node to this node
```

Now that we know the minimum amount of traversals required for any given node, the second DFS can sum up all of the potions up to the number of traversals, limited to the number of traversals required for the given node. The psuedocode representing this is:

```
set the number of potions collected to the number of potions on the current node
for each child of this node:
    DFS again
    add the child's potions to this node
limit the potions collected to the minimum number of traversals
```

The overall time complexity for this problem is **`O(nodes)`**; a linear time complexity. is Combining all of this into C++ code, we get this:

```cpp
// array definitions and #includes...

/// DFS #1: Counts the minimum number of traversals for any given node
void dfs(Node& node, int parent) {
    // if this node is a leaf node:
    if (node.children.size() == 1 && node.id != 1) {
        // add one to global number of traversals
        traversals++;
        // add one to the number of traversals for this node
        dp[node.id].first = 1;
    }
    // for each child of this node:
    for (int child : node.children) {
        if (child == parent) continue;
        // DFS again
        dfs(nodes[child], node.id);
        // add the number of traversals for the child node to this node
        dp[node.id].first += dp[child].first;
    }
}

/// DFS #2: Counts the maximum number of potions collected for any given node
void dfs2(Node& node, int parent) {
    // set the number of potions collected to the number of potions on the current node
    dp[node.id].second = std::min(potions[node.id], dp[node.id].first);
    for (int child : node.children) {
        if (child == parent) continue;
        // DFS again
        dfs2(nodes[child], node.id);
        // add the child's potions to this node
        dp[node.id].second = std::min(dp[node.id].second + dp[child].second, dp[node.id].first);
    }
    // limit the potions collected to the minimum number of traversals (done above)
}

int main() {
```
