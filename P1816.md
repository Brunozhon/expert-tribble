# Loyalty

This is a simple sparse table problem. This problem gives us a big array and asks us to find the minimum value of the array **within a given range,** which is sparse table's forte. To use a sparse table, you define a two-dimensional array with two dimensions:

1. The maximum number of elements the input array can contain.
2. The exponent of the least power of two greater than or equal to the maximum number of elements the input array can contain.

To propagate the base input array into the sparse table, you first copy the input array as such:
  

```c++
std::cin >> a;
for (int i = 0; i < n; i++) {
  st[i][0] = a[i];
}
```

> **Note:** If you're wondering why you can't just `memcpy` the input array to the spare table, it's because you are storing the input array's elements in a noncontiguous section of memory. If we use `memcpy`, the sparse table would look like this:
>
> ```c++
> [0]: XX XX XX XX XX XX XX XX ...
> [1]: 00 00 00 00 00 00 00 00 ...
> ...
> [N]: 00 00 00 00 00 00 00 00 ...
> ```
>
> As opposed to what we want, which is one input value per index of the first dimension.
>
> ```c++
> [0]: XX 00 00 00 00 00 00 00 ...
> [1]: XX 00 00 00 00 00 00 00 ...
> ...
> [N]: XX 00 00 00 00 00 00 00 ...
> ```
>
> A better optimization (which is what my code uses) is just to `std::cin` into the sparse table directly.
>
> ```c++
> for (int i = 0; i < n; i++) {
>     std::cin >> st[i][0];
> }
> ```

The actual propagation step looks a lot like merge sort ([which you can look into with much more detail in `P1908.md`](https://github.com/Brunozhon/expert-tribble/blob/main/P1908.md)), where you find the minimum two contiguous segments a power of two less than the combined segment offset a power of two apart into a bigger segment, except you do it to every starting offset of the sparse table instead of aligning to the current power of two like in merge sort. The code and formula might look intimidating, but really, it's quite simple once you get the hang of it. At the end of the file, I'll show you how to adapt this sparse table for any problem where you need to use it.

```c++
for (int j = 1; j < [MINIMUM POWER OF TWO]; j++) {
  for (int i = 0; i + (1 << (j - 1)) - 1 <= n; i++) {
    st[i][j] = std::min(st[i][j - 1], st[i + (1 << (j - 1))][j - 1]);
  }
}
```

To find the minimum element of an element in the sparse table, you first find the minimum power of two that covers more than half of the range of elements you want to query. Then, you query the sparse table from \[start, start + minimum power of 2) and (end - minimum power of 2, end\] and perform the minimum on these two ranges to get the final answer. In this case, the values are being read from standard input. **If your problem uses one-based indexing, you should uncomment the two lines of respective code.**

```c++
for (int i = 0; i < [QUERIES]; i++) {
    // input method; change for your problem
    int x, y;
    std::cin >> x >> y;
    // uncomment for one-based indexing
    // x--;
    // y--;
    int k = std::log2(y - x + 1);
    std::cout << std::min(st[x][k], st[y - (1 << k) + 1][k]) << ' ';
}
```

Since the background (like P1908) isn't important to the problem at all, the source code is pretty much a bare-bones sparse table implementation, ready to copy-and-paste. Here's the code all put together:

```c++
#include <iostream>
#include <array>
#include <cmath>

// The sparse table, stored with these dimensions:
// Outer: The maximum number of elements the input array can contain.
// Inner: The exponent of the least power of two greater than or equal to the
// maximum number of elements the input array can contain.
std::array<std::array<int, 18>, 100001> st;

int main() {
    // n: The size of the input array.
    // m: The amount of queries for the program to answer.
    int n, m;
    std::cin >> n >> m;

    // Put all of the input elements into the sparse table as segments of
    // length 2**0 (1).
    for (int i = 0; i < n; i++) {
        std::cin >> st[i][0];
    }

    // Propagate the sparse table, combining two smaller segments into one bigger
    // segment double its size for every input offset.
    for (int j = 1; j < 17; j++) {
        for (int i = 0; i + (1 << (j - 1)) - 1 <= n; i++) {
            st[i][j] = std::min(st[i][j - 1], st[i + (1 << (j - 1))][j - 1]);
        }
    }

    // Loop through each query.
    for (int i = 0; i < m; i++) {
        // Get the query from standard input.
        int x, y;
        std::cin >> x >> y;

        // Since this problem uses one-based indexing, we need to decrement the
        // variables x and y by one to get our true zero-based range, [x - 1,
        // y - 1]. You can also scale the underlying sparse table array up by
        // one in each dimension for a bit of a speedup at the cost of using
        // more memory.
        x--;
        y--;

        // Find the the minimum power of two that covers more than half of the
        // range of elements you want to query.
        int k = std::log2(y - x + 1);

        // Query the sparse table from [start, start + minimum power of 2) and
        // (end - minimum power of 2, end] and perform a minimum operation to
        // get the final answer.
        std::cout << std::min(st[x][k], st[y - (1 << k) + 1][k]) << ' ';
    }
}
```

> **Bonus I promised near the start:** Here's how to modify the sparse table algorithm to work for any sparse-table problem, not just one that required minimums. It's really simple; just find the two `std::min`s and replace them with the function you require (most likely `std::max`). **Just don't forget to require both or you'll spend an hour debugging your code.**
