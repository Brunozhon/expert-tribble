# P1171: Traveling Salesman

This is a **bitmask DP problem** because we can use a bitmask to store the villages we've visited since the input size is relatively small and we are given more memory than usual to solve this problem. Our DP array will contain two indices: one for the current village and one for the bitmask.

Our base case is at the first village, where we haven't visited any villages except for the first one yet. This element should be initialized as zero, while the others should be initialized as infinity. For our transition, we select one bit to be our current village visited and add the current distance and the DP of the previous village visited together, and then repeat and select the minimum. The psuedocode for this looks like:

```
function dp on bitmask:
    for every bit set:
        set the current village to the position of that bit
        set the previous village bitmask to the current bitmask minus that bit
        for every bit set on the previous village bitmask:
            set the DP of the current village and bitmask to the distance between the two villages plus the DP of the previous village and previous village bitmask
```

We can use a simple counter to recurse over the possible values because a counter only sets the next bit up after setting all of the possible combinations of the previous bits.

```
for i from 1 to 2^n:
    dp on bitmask
```

To get the answer, we simply recurse over every village with all bits set, and then add the distance from that to the first
